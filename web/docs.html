Documentação Oficial do Kofre

O Kofre é um gerenciador portátil de credenciais, chaves criptográficas e senhas desenvolvido especificamente para desenvolvedores, engenheiros DevOps e profissionais de segurança ofensiva e defensiva.

Instalação Rápida

O Kofre é distribuído como um binário compilado estaticamente em Go, sem bibliotecas dinâmicas ou dependências externas:

Windows (PowerShell Administrador ou Usuário):
irm https://kofre.dev/install.ps1 | iex
Linux / macOS (Bash / Zsh):
curl -fsSL https://kofre.dev/install.sh | bash
Via Go Toolchain (qualquer plataforma):
go install github.com/kofre-dev/kofre/cmd/kofre@latest

Interface Visual (TUI) & Atalhos

Ao rodar kofre sem argumentos, a interface em tela cheia do Bubble Tea é iniciada:

Tecla / Atalho Ação Descrição
↑ / ↓ ou j / k Navegação Navega entre as credenciais com rolagem suave de tela.
PgUp / PgDown Salto de Página Pula blocos de 10 credenciais por vez.
Scroll do Mouse Roda do Mouse Rola a lista suavemente para cima ou para baixo.
Enter Copiar Senha Copia a senha para a área de transferência com auto-limpeza em 45s.
c Copiar Usuário Copia o login/e-mail para a área de transferência.
u Abrir URL Abre o link do serviço diretamente no seu navegador padrão.
/ Busca em Tempo Real Filtra credenciais instantaneamente por título, usuário ou nota.
d Deleção Rápida Remove a credencial com confirmação e sync assíncrono em background.
q ou Esc Sair Fecha o cofre e limpa os buffers de memória sensível.

Referência Completa de Comandos da CLI

kofre exec & kofre shell

Injeta credenciais e chaves diretamente como variáveis de ambiente em um processo filho, sem gravá-las em arquivos .env no disco: 

# Roda o script de deploy com segredos injetados na RAM
kofre exec -- npm run deploy

# Abre um terminal temporário onde todas as chaves estão disponíveis
kofre shell

kofre import <arquivo>

Importa dados de arquivos CSV, JSON, TXT ou chaves criptográficas puras. Oferece visualização prévia antes de persistir: 

# Importa senhas do Chrome com confirmação
kofre import senhas_chrome.csv

# Importa sem prompt de confirmação (--yes)
kofre import senhas.json --yes

# Importa chave privada SSH ou Certificado A1
kofre import id_ed25519.pem
kofre import certificado.pfx

kofre cloud link & kofre login

Conecta seu computador ao Kofre Cloud Pro usando o fluxo de desafio seguro do Telegram: 

# Inicia desafio no Telegram e autentica este computador
kofre cloud link

# Conecta informando seu token manual
kofre login <seu_token_pro>

Importação do Google Chrome & Edge

O Kofre analisa o cabeçalho name,url,username,password,note do Chrome e Edge. Se o título estiver vazio, ele extrai o domínio da URL automaticamente:

Passo no Google Chrome: 1. Acesse chrome://password-manager/settings
2. Clique em Exportar senhas
3. Salve o arquivo senhas.csv
4. Execute kofre import senhas.csv
Passo no Microsoft Edge: 1. Acesse edge://wallet/passwords
2. Menu ... ➔ Exportar senhas
3. Salve o arquivo senhas.csv
4. Execute kofre import senhas.csv

Arquitetura Criptográfica Zero-Knowledge

O Kofre utiliza a combinação dos padrões mais rígidos da criptografia moderna:

  • Argon2id (RFC 9106): Derivação de chave resistente a ataques paralelos via GPU/ASIC. Configurado com 64 MB de memória, 3 iterações e salt de 16 bytes gerado por crypto/rand.
  • AES-256-GCM (Galois/Counter Mode): Criptografia autenticada. Cada gravação no cofre gera um novo Nonce aleatório de 12 bytes. Nenhuma chave ou nonce é reaproveitado.
  • Zero-Knowledge: A chave de descriptografia nunca trafega pela rede e nunca é gravada em texto plano. O backend em nuvem (S3/Railway) recebe apenas o payload binário cifrado.
